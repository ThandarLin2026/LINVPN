📖 What is a UUID?
A UUID (Universally Unique Identifier) is a randomly generated unique string used to identify data, users, devices, or sessions without duplication.

⚡ Where is UUID used?
- Databases (User IDs, Order IDs)
- APIs (Request ID, Tokens)
- Authentication (Session ID)
- Apps (Device ID)
- Tracking & Logs
- Security Systems
